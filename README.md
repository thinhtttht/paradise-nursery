# Paradise Nursery Shopping Application

Paradise Nursery is an online plant shop built with React and Redux. The application lets users browse houseplants by category, add plants to a shopping cart, update quantities, remove items, and view the total cart cost.

## Project features

- Landing page with Paradise Nursery company name and Get Started button
- About Us page with company details
- Product listing page with houseplants grouped into categories
- Add to Cart buttons that update the cart count and disable after adding
- Shopping cart page with quantity controls, delete buttons, total item cost, and total cart amount
- Navigation bar with links to Home, Plants, and Cart

## Technology used

- React
- Redux Toolkit
- React Router
- CSS
